ঘুমঘর ওয়েবসাইট — ব্যবহার নির্দেশিকা

ফাইল: index.html
ছবি: assets/ ফোল্ডারের মধ্যে

ব্যবহার:
1. ZIP ফাইলটি extract করুন।
2. index.html ফাইলটি ব্রাউজারে খুলে দেখুন।
3. নিজের Facebook Page তৈরি হলে index.html ফাইলে https://www.facebook.com/ লিংকটি আপনার পেজের URL দিয়ে বদলান।
4. assets ফোল্ডারের নমুনা ছবিগুলোর জায়গায় নিজের চাদরের আসল ছবি দিন (ফাইলের নাম একই রাখলে HTML বদলাতে হবে না)।
5. পণ্যের আসল মাপ, কাপড়ের বিবরণ, দাম ও ডেলিভারি তথ্য যাচাই করে আপডেট করুন।

এটি একটি স্ট্যাটিক, মোবাইল-ফ্রেন্ডলি এক-পেজ ওয়েবসাইট। এতে অনলাইন পেমেন্ট, কার্ট বা অর্ডার ডেটাবেস নেই; অর্ডার Facebook inbox-এ নেওয়ার জন্য তৈরি।
প্রকাশ করতে Netlify Drop বা GitHub Pages ব্যবহার করা যেতে পারে।
